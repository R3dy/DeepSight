⚡ Add a New Host

Run this command on any Linux machine to start reporting to this dashboard.

1

Run the install command

SSH into the target host and run this single command as root:

curl -sSL https://your-server.your-tailnet.ts.net:8451/install.sh | sudo bash
2

What it does

Downloads the agent script → installs Python deps → creates a systemd service → starts reporting. The agent sends RAM, CPU, GPU, disk, and process stats every 2 seconds.

3

Verify it's working

On the remote host, check the service status:

systemctl status sysdash-agent journalctl -u sysdash-agent -f
4

Select the host

Go back to the dashboard and select the new host from the dropdown menu in the header.

Requirements: Linux with Python 3 and systemd.
To remove: sudo systemctl disable --now sysdash-agent && sudo rm -rf /opt/sysdash-agent /etc/systemd/system/sysdash-agent.service
Custom hostname: edit /opt/sysdash-agent/config.json and change the "host" field.
